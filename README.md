# Quizzle – React Quiz App

- A clean and interactive multiple-choice quiz application built with **React**.  
- Test your knowledge, track your score, and get instant feedback — all in a simple, responsive UI.

## Features

- Multiple-choice questions with styled buttons
- Instant feedback on selected answers
- Final result screen with score summary
- Option to quit or restart the quiz
- Form validation for user inputs (using Formik & Yup)

## Tech Stack

- React
- React Router
- Axios
- Formik & Yup
- Tailwind CSS

## Data Source
- This app uses quiz questions from Open Trivia DB.
